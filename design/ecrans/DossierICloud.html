Les jaquettes sont trouvées automatiquement comme aujourd'hui. Un fichier ajouté au dossier depuis le PC ou le Mac apparaît à la prochaine ouverture de l'app ; un fichier retiré du dossier disparaît de la liste (ses sauvegardes restent sur l'iPhone).

La barre bouge en continu. Je ne suis pas sûr qu'iOS donne le pourcentage pour un dossier choisi par l'utilisateur : s'il le donne, la barre se remplira vraiment ; sinon, pas de faux chiffre. Un jeu SNES (quelques Mo) arrive en une seconde ; un jeu GameCube ou PSP (1 à 2 Go) prend environ une minute sur une bonne Wi-Fi. B annule. Sans Internet, message : « You're offline. This game is still in iCloud. »

Remove download enlève le jeu de l'iPhone pour libérer de la place, mais il reste dans iCloud et dans la liste (avec le nuage). Tes sauvegardes restent. Pas de fenêtre de confirmation : rien n'est perdu, le jeu se retélécharge au prochain A. Le bouton rouge « Delete » n'apparaît pas pour ces jeux : pour supprimer vraiment un jeu, on l'enlève du dossier iCloud dans l'app Fichiers. Les jeux importés avec « Add a ROM » gardent leur bouton Delete, comme aujourd'hui.

À décider

Trois questions avant de coder

  1. Libérer la place : seulement à la main avec « Remove download » (proposé), ou aussi automatiquement pour les jeux pas lancés depuis 30 jours ?
  2. Sauvegardes : elles restent sur l'iPhone (proposé, comme aujourd'hui). Les mettre aussi dans le dossier iCloud les protégerait si tu réinstalles l'app, mais c'est une fonction en plus.
  3. Jeux déjà importés : ils restent tels quels (proposé). Tu pourras les supprimer de l'app une fois copiés dans le dossier iCloud.
