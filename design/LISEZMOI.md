# Maquettes

Les fichiers `.dc.html` sont les maquettes exactes de chaque écran. Ils ne s'ouvrent pas seuls dans un navigateur, mais leur code donne toutes les valeurs : tailles, couleurs, textes, espacements.

Pour voir les écrans en vrai : https://claude.ai/artifact/CmJ6tT1J5HJSUjrppPRBKQ
